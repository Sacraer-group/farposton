# Локальный запуск через Docker Compose

Из корня репозитория выполните:

```sh
docker compose up --build
```

Откройте http://127.0.0.1:8445. Остановить приложение можно клавишами Ctrl+C
или командой `docker compose down`. Демо без авторизации доступно только на
этом компьютере и не предназначено для публикации в интернет.

Раздел Forecast использует включённые в репозиторий синтетические данные.
Демонстрационные правки и другие рабочие файлы сохраняются в отдельном томе
Docker между перезапусками. LLM и интеграция с 1С выключены.
Данные Forecast фиксированы на 29.09.2026; поэтому `/health` может сообщать
об устаревшем снимке даже при работающем демо.

Для списка заведений, истории и прогноза нужны локальные данные в `data/2gis/`
и модель в `.demo/venue-ensemble-extended-20261113-v1/`. Эти каталоги
подключаются только для чтения и не входят в образ или Git. Без них интерфейс
заведений не покажет каталог и прогноз; раздел `/forecast` продолжит работать.
Данные заведений и права на их использование необходимо проверить перед
публикацией. На чистой копии Docker создаст отсутствующие каталоги пустыми.
