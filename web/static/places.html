ПРОЗРАЧНО О ДАННЫХ

Как это работает

Мы собрали неполную выборку мест Владивостока из 2ГИС. Часы работы и сведения о заведениях могут измениться.

Демо-профиль

Для большинства точек загруженность сгенерирована для показа интерфейса. Она не измеряет посетителей и не предсказывает наличие мест.

История за месяц

Для каждой точки созданы разные почасовые демо-данные за календарный месяц. Это искусственная история, а не архив посещаемости.

Профиль 2ГИС

Для части точек есть исходные отметки 2ГИС. Их шкала и актуальность пока не подтверждены, поэтому мы не делаем по ним вывод о загруженности.
