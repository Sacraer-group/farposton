Промах — в тысячах рублей: перевезённое считается по себестоимости (треть цены), недовезённое — по упущенной марже (две трети). Строки складываются без взаимозачёта: перебор по одной позиции не гасит недобор по другой.

«Строк без заявки» — позиции, по которым сотрудник в этот день не подавал заявку. Они не входят в метрику сотрудника, чтобы не приписывать ему решение, которого не было. Собственное производство и согласованные исключения ассортимента отфильтрованы отдельно до расчёта.
