## Закрыто по итогам аудита

Добавлен явный расчёт избранных квартир (до5) и предварительная оценка уникальных запросов/остатка квоты без обращения к провайдеру. Первое нажатие показывает оценку, второе запускает расчёт; явный недостаток лимита блокирует запуск в интерфейсе. Оценка не резервирует квоту: параллельный расход может измениться, поэтому обработка неполного расчёта сохранена. По умолчанию API сохраняет прежнюю область all для совместимости, интерфейс выбирает saved. Проверки новой версии:414pytest и Chrome с тестовым провайдером; до подтверждения0 вызовов.

## Согласование с параллельным PR40

После базовой приёмки main обновил хранение избранного: решения теперь принадлежат localStorage браузера. История не импортируется из SQLite; очистка данных сайта её удаляет. При явной оценке/старте графика отправляется только нужный снимок выбора; сервер не становится хранилищем избранного. Проверки базового выпуска выше не подменяют повторную проверку объединённой версии.

После объединения:442pytest и21node прошли. Реальный Chrome подтвердил browser-local избранное, сброс оценки при изменении выбора в соседней вкладке, изоляцию другого браузера и отсутствие provider-вызовов до подтверждения. Маршрутизатор в этом браузерном тесте явно тестовый; полный живой прогон отдельно описан выше.
