# Короткая проверка пользы

## Статус

Протокол подготовлен. Реальные участники, время и ответы ниже пока не получены. Нельзя заполнять результаты вымышленными пользователями или считать автоматизацию браузера пользовательским исследованием.

## Участник и задание

Пригласить человека, выбирающего долгосрочную аренду во Владивостоке либо недавно проходившего этот процесс. Спросить согласие на запись обезличенных заметок. ФИО, текущий адрес проживания и контакты не нужны.

Зафиксировать: актуальность поиска, бюджет аренды/въезда, необходимые места и дни поездок. Для ДВФУ выбрать конкретный корпус; остальные точки также подтвердить. Участник самостоятельно должен отобрать до3 квартир, сравнить расходы и поездки и назвать вопросы перед просмотром.

## Сравнение

1. С привычным каталогом и отдельной картой: дать тот же набор предложений и те же требования. Засечь время до обоснованного короткого списка, количество действий и обращения за помощью.
2. С «Берегом»: повторить на сопоставимом наборе. При нескольких участниках менять порядок двух способов, чтобы уменьшить эффект обучения. При одном участнике прямо отметить эффект порядка и малый объём наблюдений.
3. После каждого способа попросить объяснить: сколько потребуется на въезд, какие платежи неизвестны, откуда сведения о доме и что означает время маршрута.

Не обещать экономию реального времени в дороге по одному тесту. Можно сравнить рассчитанные недельные суммы для одного графика на конкретных датах, сохранив источник и оговорку о прогнозном характере оценки.

## Метрики

| Метрика | Как измерить | Цель для пилота, не достигнутый результат |
|---|---|---|
| Время до короткого списка | Секундомер от задания до объяснения выбора | Меньше, чем при ручном сопоставлении |
| Самостоятельное прохождение | Завершил без вмешательства / число участников | Большинство в следующем пилоте; малый n показывать абсолютным числом |
| Понимание неизвестных расходов | Верно назвал неизвестные платежи | Не перепутал неизвестное с нулём |
| Полнота транспортного сравнения | Полностью рассчитанные выбранные квартиры / выбранные квартиры | Все выбранные варианты либо понятное сообщение о неполноте |
| Цена расчёта | Количество запросов, время ожидания, ошибки API | Укладывается в доступную квоту и регламент демо |
| Полезность | Ответ и конкретная причина после задания | Человек может назвать изменившее его выбор сравнение |

## Пустой бланк наблюдения

- Дата / анонимный код участника:
- Контекст поиска и места поездок:
- Порядок способов / одинаковые требования:
- Время ручного способа / время «Берега»:
- Самостоятельно завершил / требовалась помощь:
- Ошибки понимания / ошибка интерфейса / сбой API:
- Полностью рассчитано квартир из выбранных:
- Как изменился выбор и почему — фактический ответ:
- Ограничения наблюдения:
- Одно изменение продукта по результату:

До заполнения говорить «подготовили способ измерения», а не «доказали экономию».
