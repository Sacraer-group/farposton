# Заведения Владивостока: итоговые решения для MVP

Всё ниже — предложение: исходники я не читал, готовой реализации не утверждаю.

## 1. Что на чём основано
- **Подтверждено:** 4567 уникальных карточек в двух непересекающихся файлах. У 89 есть исходный `congestion` 2ГИС, у 4478 — искусственные шаблоны. Данные 2ГИС есть во всех карточках. Выборка неполная. Часовой пояс — `Asia/Vladivostok`.
- **Неизвестно:** что означают уровни 2ГИС и насколько они свежие. У всех 89 `has_dynamic_congestion=false`.
- **Синтетика:** демо-индекс 0–100 сгенерирован, связь с реальной заполненностью не доказана. Для 102 точек без расписания принято 09:00–21:00 — только для генерации.
- **Прогноза нет:** товарная модель Forecast не применялась. Слово «прогноз» в продукте не используем.
- **Столы:** ни один показатель не говорит о свободных столах.

## 2. Экраны и переходы
1. **Список** — фильтры, выбор дня и часа, строки карточек с меткой источника. Переход в карточку.
2. **Карточка** — данные заведения, расписание, сетка недели, блок «Откуда данные». Возврат в список с сохранёнными фильтрами.
3. **«О данных»** — открывается из постоянной плашки на обоих экранах.

Карту не делаем. Экраны живут под отдельными маршрутами, старые `web/app.py` и `index.html` не трогаем.

## 3. Статусы и тексты
| Статус | Текст в интерфейсе |
|---|---|
| `2gis_profile` | «Профиль 2ГИС, уровень N. Значение шкалы не расшифровано» |
| `synthetic` | «Демо-данные. Сгенерированы, реальную заполненность не отражают» |
| `closed` | «Закрыто по расписанию» |
| `schedule_assumed` | «Часы работы неизвестны, для демо принято 09:00–21:00» |
| `no_data` | «Нет данных на этот час» |

- Постоянная плашка: «Демо. Выборка неполная, праздничные дни не учтены».
- Запрещены слова «свободно», «есть места», «спокойнее», «оживлённее», «прогноз».

## 4. Календарь
- **Вариант А — сетка 7×24** (день недели × час). Идёт в карточку.
- **Вариант Б — полоса из 7 дней и выбор часа.** Идёт в список, по умолчанию «сейчас» по Владивостоку.
- **Вариант В — календарь с датами.** Отклонён: создаёт видимость прогноза на дату, а праздники не учтены.

Любой выбранный день показывается как «типовой профиль дня недели».

## 5. Модель данных и API
Поля карточки:
- `id` и описательные поля — по фактическому составу выгрузки.
- `schedule` — интервалы по дням недели, `schedule_source`: `2gis` или `assumed`.
- `profile_source`: `2gis` или `synthetic`.
- `level_2gis` — сырое число из профиля, либо `demo_index` 0–100. Это два разных поля: значения не сводятся в одну шкалу, не сравниваются и не усредняются.
- `has_dynamic_congestion`, `collected_at`.

Маршруты:
- `GET /venues` — страница.
- `GET /venues/api/list?weekday=&hour=&source=&open_only=&q=` — список.
- `GET /venues/api/{id}` — карточка.

Каждый ответ содержит `meta`: часовой пояс, дату сбора, флаг неполной выборки. Сервис читает только два локальных файла и к 2ГИС не обращается.

## 6. Фильтрация
- **Открыто в выбранный час:** интервал через полночь относится к дню начала и покрывает ранние часы следующего дня.
- **Источник:** все, профиль 2ГИС или демо.
- **Поиск:** по названию.
- **Сортировка:** по умолчанию по названию. По уровням 2ГИС не сортируем до расшифровки. По `demo_index` — только при фильтре «демо» и с подписью «демо».
- **Точки с допущенным расписанием:** не скрываем, помечаем.

## 7. План на два дня
**День 1**
1. Загрузчик двух файлов с проверками целостности.
2. Функция «открыто в момент T» с тестами.
3. Два API-маршрута.

**День 2**
1. Список с фильтрами и полосой дней.
2. Карточка с сеткой недели.
3. Тексты статусов и плашка.
4. Ручной прогон сценариев.

Данные лежат в игнорируемом `.demo/`. Не коммитим и не публикуем.

## 8. Проверки
- Загружено 4567 карточек: 89 и 4478, пересечений нет.
- У всех 89 `has_dynamic_congestion=false`.
- Ровно 102 точки помечены `schedule_assumed`.
- Тесты на расписание: через полночь, границы часа, закрытый день.
- В ответе API ни одна карточка не содержит оба показателя сразу.
- В интерфейсе нет запрещённых слов.
- Нет сетевых запросов к 2ГИС, ключа нет в коде и логах.

## 9. Вопросы, блокирующие запуск
1. **Права.** Можно ли хранить и показывать данные 2ГИС? Вопрос касается всех 4567 карточек, а не только 89 профилей. До ответа демо только локальное.
2. **Аудитория.** Демо внутреннее или внешнее? От этого зависит, блокирует ли первый вопрос показ.
3. **Семантика и свежесть уровней 2ГИС.** До ответа уровни показываются только как сырые числа.

Не блокируют: остаток квоты второго ключа (повторный сбор не планируется), праздничные расписания, неполнота выборки.

Не проверено: исходники и файлы данных не читались, поэтому имена полей и маршрутов — предположения. Главный риск: без ответа о правах на данные 2ГИС демо нельзя показывать за пределами команды.
